설치 및 실행

1단계 — 필요한 것

도구용도설치 방법
MSYS2Windows 용 패키지 관리자 / 빌드 환경msys2.org 에서 설치

SFML2D 그래픽/창 라이브러리아래 명령으로 설치

2단계 — MSYS2 터미널에서 의존성 설치

# MSYS2 MinGW 64-bit 터미널 열기 후 실행
pacman -S mingw-w64-x86_64-gcc
pacman -S mingw-w64-x86_64-sfml
주의: 반드시 MSYS2 MinGW x64 터미널을 사용하세요 (MSYS2 MSYS 터미널 아님).

3단계 — 빌드

# 소스 폴더로 이동
cd /c/Users/유저이름/Documents/Sura

# make 사용 (권장)
make

# 또는 직접 컴파일
g++ -std=c++17 -O2 main2.cpp -o SuraEngine2.exe \
    -IC:/msys64/mingw64/include \
    -LC:/msys64/mingw64/lib \
    -lsfml-graphics -lsfml-window -lsfml-system

4단계 — 실행

# 스크립트 파일 실행
./SuraEngine2.exe 파일명.sura

# REPL (실시간 모드)
./SuraEngine2.exe

# REPL 종료
exit
REPL에서는 식을 단독으로 입력하면 결과가 자동 출력됩니다. 예: 3 + 4 → 7

클래스

정의 및 인스턴스 생성

class 몬스터 do
    이름 is "몬스터"
    체력 is 100
    공격력 is 10

    func init(이름, 체력) do    # 생성자
        self.이름 is 이름
        self.체력 is 체력
    end

    func 공격 do
        print "{self.이름}이 {self.공격력} 데미지!"
    end

    func 피해(양) do
        self.체력 -= 양
        if self.체력 <= 0 then
            print "{self.이름} 쓰러짐!"
        end
    end
end

슬라임 is new 몬스터("슬라임", 50)
드래곤 is new 몬스터("드래곤", 300)

슬라임.공격()
드래곤.피해(80)
print 슬라임.체력

상속 (extends)

class 보스 extends 몬스터 do
    패턴 is 1

    func 피해(양) do        # 메서드 오버라이드
        self.체력 -= 양 / 2  # 절반만 받음
        print "{self.이름}이 저항!"
    end

    func 분노 do
        self.패턴 is 2
        print "{self.이름} 분노!"
    end
end

보스몹 is new 보스("드래곤", 500)
보스몹.피해(100)   # 오버라이드된 메서드
보스몹.분노()        # 보스 전용 메서드
보스몹.공격()        # 부모에서 상속
self는 현재 인스턴스를 가리킵니다. 메서드 내에서 필드에 접근할 때는 반드시 self.필드명을 사용하세요.

  • 변수 오류: 변수명 is 값 으로 먼저 선언했는지 확인
  • 인자 오류: 함수 호출 시 인자 개수/순서 확인
  • type x 결과로 타입을 확인해 디버깅
  • try/catch로 오류를 잡아 디버그 정보 출력

엔진 내부 구조

소스코드 (.sura)
    ↓  lexer.hpp        문자열 → 토큰 스트림
    ↓  parser.hpp       토큰 → AST 트리
    ↓  ast.hpp          트리 노드 구조체 정의
    ↓  value.hpp        Value 타입 (숫자/문자열/bool/nil/배열/딕셔너리)
    ↓  interpreter.hpp  AST 순회 실행 (트리-워크)
    ↓  platform.hpp     크로스플랫폼 (Windows / macOS / Linux)
    ↓  main2.cpp        진입점 — REPL + 파일 실행

lexer.hpp

소스 문자열을 토큰 목록으로 변환. 키워드, 연산자, 문자열 리터럴, 숫자 처리.

parser.hpp

재귀 하강 파서. 토큰을 AST로 변환. elif 는 중첩 if로 탈당.

value.hpp

Value 구조체 — 모든 런타임 값. 배열/딕셔너리는 shared_ptr 기반 RC.

interpreter.hpp

Scope 스택, 제어 흐름 신호(BreakSignal 등), 내장 명령 실행기.

RPG 전투

class 캐릭터 do
    이름 is "캐릭터"
    체력 is 100
    공격력 is 20

    func init(이름, 체력, 공격력) do
        self.이름 is 이름
        self.체력 is 체력
        self.공격력 is 공격력
    end

    func 공격(대상) do
        rand_int 1 self.공격력 피해량
        print "{self.이름} → {대상.이름} {피해량} 데미지"
        대상.체력 -= 피해량
    end

    func 살아있음 do
        return self.체력 > 0
    end
end

용사 is new 캐릭터("용사", 100, 25)
슬라임 is new 캐릭터("슬라임", 40, 10)

print "=== 전투 시작 ==="

while 용사.살아있음() and 슬라임.살아있음() do
    용사.공격(슬라임)
    if 슬라임.살아있음() then
        슬라임.공격(용사)
    end
end

if 용사.살아있음() then
    print "용사 승리! 남은 체력: {용사.체력}"
else
    print "슬라임 승리!"
end
