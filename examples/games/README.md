# 게임 예제

터미널과 Windows 드로잉 API로 만든 놀 수 있는 예제들입니다.

```powershell
.\SuraLanguage.exe examples\games\rpg.sura
.\SuraLanguage.exe examples\games\dungeon3d.sura
```

| 파일 | 내용 |
| --- | --- |
| `rpg.sura` | 텍스트 RPG — 직업, 전투, 층 진행 |
| `dungeon3d.sura` | 1인칭 레이캐스팅 던전 |
| `space3d.sura` / `space3d_v2.sura` / `space3d_win.sura` | 3D 슈터 변형들 |
| `click_test.sura` | 마우스 입력 데모 |

`dungeon3d.sura`와 `space3d.sura`는 `-- --smoke`를 붙이면 창을 띄운 채
몇 프레임만 렌더링하고 끝나므로 자동 검증에 쓸 수 있습니다.
